# Changelog



## Draw.io v1.0.0

### Added
* List and view draw.io files: `.drawio`, `.svg`, `.png` from all project repositories and wikis.
* Create new diagrams.
* Rename existing diagrams.
* History tracking for diagram files.
* Support for light and dark theme.
* Work in the fullscreen mode.



## Draw.io v1.0.1

### Fixed
* Accented characters become corrupted when reopening .drawio files.
